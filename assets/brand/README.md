# LOKAL AI brand assets

Official identity assets. The LA symbol is the primary visual signature; keep its geometry and gradient consistent.

- `lokal-logo.svg`: horizontal primary wordmark for website headers and landing pages.
- `lokal-app-icon.svg`: square app icon, 512×512 viewBox.
- `lokal-favicon.svg`: simplified 64×64 browser favicon.
- `lokal-mark-minimal.svg`: standalone mark for navigation and compact UI.

Palette: neon turquoise `#00F0B5`, electric blue `#238BFF`, neon purple `#A855F7`; dark base `#070D18`.

SVG files are the canonical vector sources. PNG exports should be rasterized from these sources at the required platform sizes to avoid visual drift.
